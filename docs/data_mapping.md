# AquaGuard AI 데이터 매핑표

| 신청서류 번호 | 신청서류 데이터명 | 실제 경로 | 주요 활용 지표 |
|---:|---|---|---|
| ① | 농업용저수지 수위조회 | data/raw/01_reservoir | 저수율 위험도, 저수량, 수혜면적, 대체 수원 후보 |
| ② | 관정현황 | data/raw/02_well | 관정 수, 양수능력, 보조 수원 가능성 |
| ③ | 재배작물별 농가현황 | data/raw/03_crop | 작물 물수요 지수, 논벼 생산성 |
| ④ | 시·군별 강우량/가뭄 관련 데이터 | data/raw/04_weather_drought | 강우 부족도, 가뭄 위험도 |
| ⑤ | 농축어업 통계 | data/raw/05_agri_stats | 농가 수, 농가인구, 농업 수혜 규모, 행정 우선순위 보정 |

## ⑤ 농축어업 통계 처리 원칙

⑤ 농축어업 통계는 단일 파일 하나만 의미하지 않는다.

- 농가 수 / 농가인구: data/raw/05_agri_stats
- 저수지 수혜면적 / 저수량 / 저수율: data/raw/01_reservoir 및 data/raw/04_weather_drought에서 파생
- 작물 생산성: data/raw/03_crop에서 파생

최종 전처리 단계에서 ⑤ 농축어업 영향도 지표를 별도로 생성한다.
