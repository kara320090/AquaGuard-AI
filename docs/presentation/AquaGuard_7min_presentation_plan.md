# AquaGuard AI 7분 발표 계획

## 1. 발표 기준

이 문서는 현재 Streamlit 대시보드 UI를 기준으로 7분 발표와 3분 질의응답을 준비하기 위한 실행 계획입니다.

발표의 핵심 흐름은 모든 기능 소개가 아니라 의사결정 흐름입니다.

1. 어디가 위험한가?
2. 왜 위험한가?
3. 어떻게 대응할 것인가?
4. 어떤 저수지 시설을 먼저 점검할 것인가?
5. 최신 공개데이터 갱신과 AI 해석 기준은 어떻게 분리되는가?

주의할 표현:
- "사이드바에서 당진시를 선택한다"라고 말하지 않습니다.
- 사이드바의 `전체 지역` 체크박스와 시·군별 체크박스는 분석 범위를 조정하는 기능입니다.
- 특정 지역의 상세 해석은 각 탭 내부 selectbox에서 선택합니다.

현재 UI 기준:

| 화면 | 현재 선택 구조 | 발표에서 말할 방식 |
| --- | --- | --- |
| Main dashboard | 사이드바 `분석 기준` radio, `전체 지역` 체크박스, 시·군별 체크박스, `위험등급` multiselect | 사이드바에서는 분석 범위와 위험등급만 조정한다고 설명 |
| Main dashboard tabs | `지도 보기`, `위험도 분석`, `점검·대체수원`, `원본·기타` | 의사결정 흐름 1~3단계로 사용 |
| `위험도 분석` tab | 탭 내부 `위험 구성요소 확인 대상` selectbox | 지역별 위험 원인은 탭 내부 selectbox에서 확인한다고 설명 |
| `점검·대체수원` tab | 탭 내부 `대체 수원 확인 대상` selectbox | 대체 수원 후보는 탭 내부 selectbox로 대상 지역을 바꾼다고 설명 |
| Reservoir Watchlist | 사이드바 지역 체크박스, `Watch 등급` multiselect, 탭 내부 `시설 점검 시·군 선택` selectbox | 시설 점검 우선순위는 별도 Watchlist 화면에서 확인한다고 설명 |
| Deep AI Insights | `AI 비교 기준월` selectbox, 지역 체크박스, `Deep AI 등급` multiselect, 탭 내부 상세 지역 selectbox | AI는 2026년 Live 데이터를 직접 관측했다고 말하지 않고, 학습 데이터 범위의 전년도 동일 월 비교라고 설명 |
| Live Data Update | 지역 체크박스, `Live 위험등급` multiselect, `최신 원천데이터 반영 지역만 보기` checkbox | 운영 신뢰성 확인 화면으로만 짧게 제시 |

## 4. 슬라이드별 발표 스크립트

### Slide 1. AquaGuard AI 소개

안녕하세요. AquaGuard AI는 충남 공개데이터를 활용해 농업용수 부족 위험 지역을 찾고, 위험 원인과 점검 우선순위, 대체 수원 후보까지 제시하는 의사결정 대시보드입니다. 단순히 데이터를 나열하는 것이 아니라, 담당자가 지금 어디를 먼저 확인해야 하는지 빠르게 판단하도록 만든 서비스입니다.

### Slide 2. 문제 정의

농업용수 부족은 저수율 하나만으로 판단하기 어렵습니다. 같은 저수율이라도 최근 강우, 토양수분, 관정 의존도, 작물 물수요, 대체 수원 접근성에 따라 실제 위험도는 달라집니다. 그래서 이 프로젝트의 질문은 “어디가 위험한가”에서 끝나지 않습니다. 왜 위험한지, 그리고 어디를 먼저 점검해야 하는지까지 연결해야 합니다.

### Slide 3. 데이터 파이프라인

AquaGuard AI는 OLDAM 저수지 snapshot, 기상청 AWS/ASOS, ADMS 토양수분, 관정, 작물, 대체 수원 데이터를 결합합니다. 각 데이터는 시·군 단위로 정리되고, 최종 위험도, Live 업데이트 위험도, Reservoir Watchlist, 대체 수원 후보, Deep AI 해석으로 이어집니다. 이 구조 덕분에 발표 화면에서는 한 가지 지표가 아니라 여러 근거를 함께 설명할 수 있습니다.

### Slide 4. 위험도 모델과 검증

위험도는 강우 부족도, 저수율 위험도, 관정 의존도, 작물 물수요, 대체 수원 접근성 부족도를 결합해 산정합니다. 모델과 대시보드 산출물은 최종 검증 스크립트로 점검했고, 발표에서는 존재하는 검증 지표만 보여줍니다. 즉, 숫자를 새로 꾸미거나 없는 성능 지표를 만들지 않고, 현재 결과 파일에 있는 값만 사용합니다.

### Slide 5. 어디가 위험한가?

지금 보시는 화면은 메인 대시보드의 `지도 보기` 탭입니다. 사이드바에서는 `전체 지역`과 시·군별 체크박스로 분석 범위를 조정하고, 지도에서는 위험점수와 위험등급을 한눈에 확인합니다. 이 단계의 목적은 “오늘 어느 지역을 먼저 볼 것인가”를 빠르게 좁히는 것입니다.

### Slide 6. 왜 위험한가?

다음은 `위험도 분석` 탭입니다. 여기서는 단순 순위만 보는 것이 아니라 위험 점수의 원인을 나눠 봅니다. 위험 순위와 분포를 먼저 확인하고, `위험 구성요소 확인 대상` selectbox에서 지역을 선택하면 해당 시·군의 강우 부족도, 저수율 위험도, 관정 의존도, 작물 물수요, 대체 수원 접근성 부족도가 어떻게 점수에 기여했는지 볼 수 있습니다.

### Slide 7. 어떻게 대응할 것인가?

`점검·대체수원` 탭에서는 분석 결과를 대응으로 연결합니다. 위쪽에서는 현재 필터 기준 우선 점검 지역과 권고 조치를 확인합니다. 아래쪽에서는 `대체 수원 확인 대상` selectbox로 대상 시·군을 고르고, 거리, 저수율, 수혜면적, 후보점수를 기준으로 대체 수원 후보를 확인합니다. 이 화면은 “위험하다”에서 끝나지 않고 “어떻게 움직일 것인가”로 이어지는 부분입니다.

### Slide 8. 어떤 시설부터 점검할 것인가?

Reservoir Watchlist는 시·군 위험도를 저수지 시설 점검으로 연결하는 화면입니다. Watchlist 요약 탭에서는 먼저 봐야 할 시·군을 확인하고, `저수율·시설 점검` 탭에서는 선택한 시·군의 평균 저수율, 최저 저수율, Watch 판정 사유를 한 번만 요약해 보여줍니다. 시설 표에는 지역 공통 지표를 반복하지 않고, 시설 점검 순위, 저수지명, 시설 규모점수, 시설 점검 우선점수, 우선순위 사유를 중심으로 표시합니다.

### Slide 9. 운영 신뢰성: Live 갱신과 AI 해석

마지막 기능 영상은 Live Data Update와 Deep AI Insights를 함께 보여줍니다. Live Data Update는 최신 공개데이터가 위험도에 어떻게 반영됐는지 확인하는 운영 신뢰성 화면입니다. Deep AI Insights에서는 2026년 Live 데이터를 AI가 직접 관측했다고 말하지 않습니다. 현재 Live 기준일과 AI 비교 기준월을 분리해서 보여주며, 학습 데이터 범위 안에서 계절성이 같은 전년도 동일 월, 예를 들어 2026년 5월 Live 상황이면 2025년 5월을 비교 기준으로 사용합니다.

### Slide 10. 기대 효과와 마무리

AquaGuard AI의 기대 효과는 세 가지입니다. 첫째, 고위험 시·군을 빠르게 찾을 수 있습니다. 둘째, 왜 위험한지 근거를 설명할 수 있습니다. 셋째, 어떤 저수지 시설과 대체 수원 후보를 먼저 볼지 정리할 수 있습니다. AquaGuard AI는 충남 농업용수 리스크를 데이터 기반으로 설명하고, 행정 대응의 우선순위를 정하는 의사결정 지원 도구입니다. 감사합니다.

## 6. 녹화 실패 체크리스트

녹화 전 확인:

- 브라우저 zoom은 80~90%로 맞춥니다.
- 화면 비율은 16:9로 맞춥니다.
- 터미널, 개인 경로, API key, 브라우저 주소창의 민감 경로가 보이지 않게 합니다.
- Streamlit 로딩 spinner가 3초 이상 지속되면 녹화를 다시 시작합니다.
- `None`, `nan`, `NaN`, `NaT`, `<NA>`가 표에 보이면 녹화하지 않습니다.
- 한글이 네모 문자로 깨진 PNG는 사용하지 않습니다.
- Streamlit traceback이나 빨간 오류 박스가 보이면 녹화하지 않습니다.
- Reservoir Watchlist 시설 표에 같은 시설 중복 행이 보이면 녹화하지 않습니다.
- Deep AI 비교 기준월이 데모 문맥에서 2025-12로만 보이면 안 됩니다. 2026년 5월 Live 문맥에서는 2025-05 비교 기준을 사용합니다.
- 표가 비어 있으면 해당 장면을 건너뛰거나 데이터가 있는 지역으로 탭 내부 selectbox를 바꿉니다.

녹화 중 금지:

- 사이드바에서 상세 대상 지역을 고른다고 설명하지 않습니다.
- AI가 2026년 데이터를 직접 학습하거나 예측했다고 말하지 않습니다.
- Watchlist 시설 점검 우선점수를 시설별 실시간 저수율이라고 설명하지 않습니다.
- 모든 기능을 설명하려고 시간을 늘리지 않습니다.

- 슬라이드마다 제목은 하나만 둡니다.
- 슬라이드마다 핵심 문장은 하나만 둡니다.

## 8. 3분 Q&A 백업 포인트

예상 질문 1: 왜 저수율 하나만 쓰지 않았나요?

답변: 저수율은 중요한 지표지만 최근 강우, 토양수분, 관정 의존도, 작물 물수요, 대체 수원 접근성과 함께 봐야 실제 대응 우선순위를 설명할 수 있습니다.

예상 질문 2: AI가 2026년 5월을 직접 예측한 건가요?

답변: 아닙니다. Live 데이터는 2026년 최신 공개데이터를 사용하지만, AI 해석은 학습 데이터 범위 안에서 계절성이 같은 전년도 동일 월을 비교 기준으로 사용합니다.

예상 질문 3: 시설별 저수율을 만든 건가요?

답변: 아닙니다. 시설별 실시간 저수율이 직접 제공되지 않는 경우에는 시·군 단위 저수율 위험도와 시설 규모 정보를 결합해 행정 점검 우선순위를 산정했습니다.

예상 질문 4: 점수가 높으면 바로 현장 조치가 필요한가요?

답변: 대시보드는 행정 의사결정 지원 도구입니다. 현장 조치 여부는 실제 현장 상황, 관로, 수리권, 지자체 운영 판단과 함께 최종 결정해야 합니다.
